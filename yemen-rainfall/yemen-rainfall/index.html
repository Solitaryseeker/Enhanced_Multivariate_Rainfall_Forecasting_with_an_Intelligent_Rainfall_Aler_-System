Methodology

Where each value comes from

Temporal features

month_sin = sin(2π·month/12), month_cos = cos(2π·month/12), dekad_sin = sin(2π·dekad/3), dekad_cos = cos(2π·dekad/3). The training data stores dekad as the starting day (1, 11 or 21), and the same value is used in the formulas, so the app derives it from the day of month.

Historical lags and window

rfh_lag_1, 2, 3, 6 and 12 are earlier raw rfh values of the same PCODE (not log-transformed in training). The model reads a 24-dekad window, so the backend needs at least 35 consecutive prior dekads for the chosen PCODE.

Regional encoding and preprocessing

PCODE is an integer index (0–317) feeding a learned 32-dimensional embedding. rfh, r1h and r3h are log1p-transformed, then 14 features are MinMax-scaled with scalers fitted on data up to 2015-12-31. The target is scaled by its own scaler.

Inference and alerts

Feature order: rfh, r1h, r3h, rfh_lag_1/2/3/6/12, month_sin, month_cos, dekad_sin, dekad_cos, month, dekad. The iTransformer treats each feature as a token across 24 steps. The output is inverse-scaled, then expm1 converts it to millimetres for the next dekad. That millimetre value is compared with the editable thresholds.

Deployment architecture and backend contract (v1.0)

Browser (this page, static) → HTTP JSON → Python server (server.py) → iTransformer checkpoint, fitted scalers and historical series. The browser never computes a forecast. Alerts are applied in the browser to the returned millimetre value, using the editable thresholds.

GET /api/health returns {contract_version, model, seq_len, model_loaded, missing[], error}.
POST /api/predict takes {date, pcode, rfh, r1h, r3h} (year, month, dekad and sin/cos values are also sent, but the server recomputes them). Success returns {predicted_mm, unit, target_date, window}. Errors return {code, error} with VALIDATION_ERROR (400), MODEL_NOT_LOADED (503) or INFERENCE_ERROR (500).

To use another host, set CONFIG.apiBase in index.html. Any server that honours this contract can replace server.py.
